## 五、统一版 main.cpp 素描

```cpp
// 三个模块同时在线
MqttClient mqtt;
GatewayClient cloud;
AudioI2S audio;
FrameDiff fd;

setup():
  WiFi → MQTT.begin(EMQX) → audio.begin() → camInit() → fd.begin()
  cloud.beginConversation()

loop():
  mqtt.loop()        // MQTT 心跳
  wifiMonitor()       // WiFi 重连
  checkHeap()         // 内存告警
  
  if (idle):
    poll SU-03T / Serial
    if triggered → runConversation()
    else → frameDiff巡逻()

  frameDiff巡逻:
    fb = camera.get() → fd.process(fb)
    if anomaly:
      snapshot → TOS → doubao
      → 告警分级 → MQTT alert / 语音播报
```
