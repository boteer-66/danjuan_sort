## 一、设备遥测面板——替换两个字段

当前小程序 `index.wxml` 的 "设备遥测" 卡片有三行指标，改其中两行：

### 改动前

| 指标 | 字段 | 单位 |
|------|------|------|
| 📡 WiFi 信号 | `{{rssi}}` | dBm |
| 🧠 空闲内存 | `{{free_heap}}` | B |
| 📦 待传队列 | `{{img_queue}}` | 张 |

### 改动后

| 指标 | 字段 | 单位 | 说明 |
|------|------|------|------|
| 📡 WiFi 信号 | `{{rssi}}` | dBm | 保留不动 |
| 📸 TOS 上传 | `{{tos_status}}` | — | idle / uploading / ok / fail |
| ⚠️ 今日告警 | `{{alert_count}}` | 次 | 当天累计异常次数 |

## 二、ESP32 侧 MQTT 补充字段

### telemetry 主题新增

ESP32 在 `danjuan_1129_66/device/telemetry` 的 JSON 里新增两个字段：

```json
{
  "device_id": "danjuan_1129_66",
  "rssi": -55,
  "free_heap": 220000,
  "sd_ready": false,
  "cam_ready": true,
  "uptime": 3600,
  "img_queue": 0,
  "tos_status": "ok",
  "alert_count": 3
}
```

| 新字段 | 类型 | 值 |
|------|------|------|
| `tos_status` | String | `"idle"` / `"uploading"` / `"ok"` / `"fail"` |
| `alert_count` | int | 当日累计异常次数（UTC+8 天为界） |

### 小程序 JS 新增 data 字段

```js
// index.js data 中新增
tos_status: 'idle',
alert_count: 0,

// MQTT telemetry 消息处理中新增
that.setData({
  rssi: data.rssi,
  tos_status: data.tos_status || 'idle',
  alert_count: data.alert_count || 0
});
```

---

## 三、UI 建议

- `tos_status == 'ok'` 时显示绿色 ✓
- `tos_status == 'fail'` 时显示红色 ✗
- `tos_status == 'uploading'` 时显示动画 ⏳
- `alert_count > 0` 时数字加红底圆点

---

## 四、旧字段处理

- `free_heap` 和 `img_queue` 可以保留在 JS data 中但不渲染
- ESP32 侧 `publishTelemetry()` 继续传 `free_heap` 和 `img_queue`，向前兼容
